How FindIt would work

    Work Breakdown Structure

    The project is split into phases, and each phase into the activities the team will carry out. Each activity has a WBS code (phase.activity).

    Activity sequencing

    Each activity starts only after its predecessors finish (finish-to-start). The orange path is the critical path: a delay on any of these activities delays the whole project.

    IDActivityPredecessorsSuccessorsRelationship

    Activity duration estimates

    Durations are the team's most likely estimate in working days (Monday to Friday). Slack is how many days an activity can slip without delaying the finish date.

    WBSIDActivityAssigned toDuration (days)StartFinishSlack (days)Critical

    Dates assume work starts on the project start date and skip weekends. Holidays and class suspensions are not deducted.

    Gantt chart

    Bars show when each activity runs. Outlined bars are on the critical path.

    Team member assessment

    Before assigning roles, the team discussed each member's skills and strengths, using the work personalities from the lesson: Deliverer, Prototype, Perfector, Producer, Fixer and Finisher.
